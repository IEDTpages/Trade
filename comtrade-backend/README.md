# Локальный служебный API

Сервис принимает `POST /api/comtrade`, последовательно обращается к официальному
API UN Comtrade и передаёт результат локальному интерфейсу.

Обычному пользователю не требуется запускать эту папку отдельно: используйте
`ЗАПУСТИТЬ_КОНСТРУКТОР.bat` в корне комплекта.

Проверка разработчиком:

```bash
npm ci
npm test
```

Основные настройки по умолчанию:

- `MAX_RECORDS=50000`;
- `REQUEST_INTERVAL_MS=1100`;
- `UPSTREAM_TIMEOUT_MS=180000`;
- `MAX_RETRIES=3`.
