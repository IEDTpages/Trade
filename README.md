# UN Comtrade Builder — GitHub Pages v10

Эта сборка повторяет функции локальной версии `UN-Comtrade-Local-Windows-v10-export-unit-labels` и использует лимит 50 000 строк на один запрос.

## Что включено

- годовые данные, диапазон месяцев и выбор отдельных месяцев;
- страны, регионы, группы/подгруппы грузов, HS4 и HS6 с взаимной фильтрацией;
- режимы TOTAL, AG4, AG6 и `aggregateBy=cmdCode`;
- автоматическое последовательное разбиение запросов;
- динамика стоимости и массы, географическая и товарная структура;
- интерактивные фильтры и полные списки без объединения в «Прочие»;
- CSV, Excel, PNG, PDF и PowerPoint;
- динамические заголовки по выбранным странам, регионам, потоку и товару;
- актуальные подписи единиц измерения в интерфейсе и экспорте.

## Публикация

1. Разверните backend по инструкции `DEPLOY_ALWAYSDATA.md`.
2. В `config.js` замените `YOUR-ACCOUNT` на имя аккаунта alwaysdata.
3. Загрузите содержимое этого архива в корень GitHub-репозитория.
4. В `Settings → Pages` выберите `Source: GitHub Actions`.
5. Запустите workflow `Deploy UN Comtrade Builder to GitHub Pages`.
6. После публикации обновите страницу через `Ctrl+F5`.

Статические файлы поддерживают как корневой домен, так и стандартную подпапку вида `https://USER.github.io/REPOSITORY/`.

## Проверка

Откройте в браузере:

```text
https://YOUR-ACCOUNT.alwaysdata.net/health
```

В ответе должно быть `"maxRecords":50000`. Затем откройте GitHub Pages и убедитесь, что в верхней панели указано `Лимит одной части: 50 000 строк`.
